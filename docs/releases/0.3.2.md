# PageBox 0.3.2

This hotfix improves authenticator enrollment and management.

- Align the **I have saved my recovery codes** checkbox with its label using the shared checkbox style.
- Use one current-password field for **Replace recovery codes** and **Disable two-factor authentication**, with a separate button for each action. Each operation still verifies the password on the server. Disabling remains unavailable when the administrator requires 2FA.
- Show an enabled status badge and explain how to change the icon in Authy. [Authy chooses its own logo for ordinary TOTP tokens](https://help.twilio.com/articles/19753405130523); PageBox cannot force its icon through the QR image hint. In Authy, open **Settings → Accounts → PageBox → Edit logo**.

## Upgrade from 0.3.1

Select `PAGEBOX_TAG=0.3.2` and restart PageBox. No new database migrations, DNS, proxy or TLS changes are needed. Existing authenticators, recovery codes and the instance-wide 2FA policy continue working without re-enrollment.

For earlier versions, follow [the upgrade procedure](../../DEPLOYMENT-SECURITY.md).

The 11 two-factor integration tests pass, including a Chromium check of checkbox alignment and enrollment, sign-in, recovery-code replacement and disabling. The browser exercises both action buttons with the shared password field. Required-policy checks confirm disabling remains blocked.
