# PageBox 0.4.0

Any site can now be served from the root of its own domain, set per site in the panel.

- An admin who owns a site sets its domain under **Domain** on the site page. PageBox picks the site from the request's `Host` header and serves its build from `/`, so the site's base path becomes `/`. Without a domain, the site stays at `<PAGEBOX_SITES_HOST>/s/<slug>/`.
- Links to `/s/<slug>/…` on the sites host are forwarded to the domain, with the prefix removed. For a private site the sign-in check runs first.
- Private sites keep signing readers in on `PAGEBOX_SITES_HOST`. After sign-in the reader returns to the domain with a one-time code, and the domain sets its own host-only cookie.
- Changing or removing a domain signs readers out of that site and switches its base path. Rebuild the site and deploy it again.
- `GET /api/v1/whoami` reports `"mode": "domain"` or `"path"`, the `hostname`, and the base path to build for.
- `PAGEBOX_SITE_SUBDOMAINS` and the generated `<slug>-<id>.<PAGEBOX_SITES_HOST>` hosts are removed. The variable is ignored.

## Routing a domain in Dokploy

1. In the panel, open the site, go to **Domain**, enter `docs.example.org` and save.
2. Point the domain's DNS at the Dokploy server.
3. In Dokploy, on the same PageBox application, open **Domains → Add Domain**: host `docs.example.org`, path `/`, internal path empty, strip path off, container port `3000`, HTTPS on.
4. Rebuild the site for base path `/` and deploy it.

Do not set an internal path such as `/s/<slug>`. PageBox expects the request unchanged. See [the Dokploy guide](../dokploy.md#a-site-on-its-own-domain).

## Upgrade from 0.3.2

Select `PAGEBOX_TAG=0.4.0` and restart PageBox. No database migration is needed. Sites keep their `/s/<slug>/` URLs and their builds keep working. If the instance ran with `PAGEBOX_SITE_SUBDOMAINS=true`, the generated hosts stop answering: give each site that needs its own origin a domain, route it, and rebuild that site for `/`.

For earlier versions, follow [the upgrade procedure](../../DEPLOYMENT-SECURITY.md).
