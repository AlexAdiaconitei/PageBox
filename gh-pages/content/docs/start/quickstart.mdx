---
title: Quickstart
description: Run PageBox 0.4.0 locally.
---

Clone the repository for the Compose file and the storage policy example:

```bash
git clone https://github.com/AlexAdiaconitei/PageBox.git
cd PageBox
cp .env.example .env
```

Set PAGEBOX_TAG=0.4.0 and fill every blank secret before running Compose. Generate a unique
AUTH_SECRET and chosen database, storage administrator, app storage and bootstrap
credentials. The app storage key must differ from the storage administrator key.

Start only the infrastructure while provisioning storage:

```bash
docker compose up -d postgres minio
```

Create the bucket and a dedicated application user. Apply storage-policy.example.json,
using your bucket name in both ARNs. Set S3_ACCESS_KEY and S3_SECRET_KEY to that user and
keep PAGEBOX_ENSURE_BUCKET_ON_START=false. The root DEPLOYMENT-SECURITY.md contains the
provisioning and migration instructions.

For local HTTP development, keep the example pagebox.localhost and pages.localhost hosts
and start the supplied proxy:

```bash
docker compose --profile proxy up -d
```

Open http://pagebox.localhost/ and log in with the bootstrap account. Replace its password
when prompted. Create a site and upload a built ZIP. Its URL contains the immutable site
ID beneath pages.localhost; the central reader host serves login and authorization.

Production needs wildcard DNS, proxy routing and TLS. Review [the security upgrade
procedure](/docs/operate/security) before exposing the instance. Do not expose PostgreSQL,
MinIO or the direct app port through a public tunnel.
