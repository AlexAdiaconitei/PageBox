PageBox is static hosting you run yourself. It never builds anything: it receives an
artifact that is already built — a `dist/`, a zip, a lone `index.html` — stores it whole,
and serves it under `/s/<slug>/`. A site is public or private, and on a private one every
asset goes through the authorisation check, not just the HTML.

## What PageBox does not do

It is worth being clear early, because the shape of everything else follows from it.

- **It does not build.** No repository is cloned, no install step runs, no framework is
  detected. You build, and you send the result.
- **It does not have a sign-up page.** Accounts are issued by somebody who already has one.
- **It does not give each site a hostname yet.** Every site lives under a path on one
  hostname, `/s/<slug>/`. That is why base paths matter so much here.
- **It does not delete a build to make room for a new one unless you ask.** Every
  deployment is kept whole, which is what makes rollback a pointer move — and what makes
  [retention limits](/docs/operate/storage) worth setting.
