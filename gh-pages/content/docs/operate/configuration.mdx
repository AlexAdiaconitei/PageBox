An invalid configuration stops the process with a list of what is wrong, rather than serving
traffic with a missing secret. Everything without a default is required.

## Hosts

| Variable                | Default             | Notes                                                                               |
| ----------------------- | ------------------- | ----------------------------------------------------------------------------------- |
| `PAGEBOX_ADMIN_HOST`    | `pagebox.localhost` | the panel and the API                                                               |
| `PAGEBOX_SITES_HOST`    | `pages.localhost`   | central reader login; sites under `/s/<slug>/` when they have no domain             |
| `PAGEBOX_SITES_PREFIX`  | `/s`                | the path segment sites live under                                                   |
| `PAGEBOX_PUBLIC_SCHEME` | `http`              | used to build absolute URLs behind a tunnel. Never derived from `X-Forwarded-Proto` |
| `PAGEBOX_REPLICAS`      | `1`                 | more than one requires `REDIS_URL`                                                  |

<Callout type="warn" title="The two hostnames must differ">
  If they match, the process exits at startup. Hosted static content would otherwise be able to call
  the admin API with the admin cookie attached.
</Callout>

| -------------------------- | ------------------------------------------------------------------ |

<Callout type="info" title="Choose production credentials">
  The examples leave secrets blank. Production startup rejects known placeholder auth, bootstrap,
  database and storage credentials, including under `*.localhost`.
</Callout>

## Behind a proxy

```bash
# XFF_DEPTH=1
```

The entrypoint uses the actual Host header and socket address by default. Set HOST_HEADER,
PROTOCOL_HEADER and ADDRESS_HEADER only behind a trusted proxy that replaces incoming
forwarding headers and prevents direct external access to the app.

`XFF_DEPTH` says how many proxies sit in front. It decides which hop of `X-Forwarded-For` is
taken as the client, and **that address is what rate limiting and the audit trail key on**.

| In front                           | Value             |
| ---------------------------------- | ----------------- |
| Traefik alone, or Cloudflare alone | `1` (the default) |
| Cloudflare **and** Traefik         | `2`               |

<Callout type="warn" title="Getting this wrong disables rate limiting">
  Leave it at `1` with two proxies and every caller looks like the inner proxy — so one attacker
  exhausts the login budget for everybody.
</Callout>

Do **not** set `ORIGIN`. A fixed origin collapses the two hostnames into one and disables the
host split.

## Sizes

Every `*_BYTES` setting takes a unit, or a plain number of bytes:

```bash
PAGEBOX_STORAGE_BYTES=1GB        # also: 1gb, 500MB, 1.5GB, 2TB, 512K
MAX_UPLOAD_BYTES=104857600       # a bare number is still bytes
```

Units are **1024-based**, and `GB` and `GiB` mean the same thing — `1GB` is `1073741824`.
That is deliberate: the panel divides by 1024 and prints `GB`, so a decimal reading here
would answer `931.3 GB` to somebody who typed `1TB`.

A value it cannot read is refused at boot with the variable named. It does not take the
digits off the front of a typo: `100 MB free` is not 100 MB.

## Storage quotas

| Variable                      | Default | Notes                                                                                                                  |
| ----------------------------- | ------- | ---------------------------------------------------------------------------------------------------------------------- |
| `PAGEBOX_STORAGE_BYTES`       | unset   | what the instance has to give away. A declaration, not a measurement — S3 exposes no capacity figure                   |
| `PAGEBOX_DEFAULT_QUOTA_BYTES` | `5GB`   | what a newly seated admin is offered on the form. Existing admins are given it once, at the first boot after upgrading |

`PAGEBOX_DEFAULT_QUOTA_BYTES` may not exceed `PAGEBOX_STORAGE_BYTES`; a pool smaller than
the default quota stops the process at boot rather than at the first attempt to seat an
admin. Declaring `PAGEBOX_STORAGE_BYTES=1GB` means lowering the default quota too.

The full model is on [storage and retention](/docs/operate/storage#quotas).

## Limits

| Variable                      | Default | Is                                                                  |
| ----------------------------- | ------- | ------------------------------------------------------------------- |
| `MAX_UPLOAD_BYTES`            | `100MB` | the request body cap. Also becomes adapter-node's `BODY_SIZE_LIMIT` |
| `MAX_UPLOAD_TEMP_BYTES`       | `400MB` | reserved capacity for admitted temporary archives                   |
| `MAX_CONCURRENT_UPLOADS`      | `4`     | global admission slots across processes and replicas                |
| `UPLOAD_BODY_TIMEOUT_SECONDS` | `60`    | deadline for receiving an archive                                   |
| `UPLOAD_TIMEOUT_SECONDS`      | `600`   | overall ingestion deadline                                          |
| `MAX_UNCOMPRESSED_BYTES`      | `500MB` | what an archive may expand to                                       |
| `MAX_FILES`                   | `20000` | entries per archive                                                 |
| `MAX_ZIP_RATIO`               | `100`   | compression ratio over this is treated as a bomb                    |

The 100 MB default exists because Cloudflare's proxy rejects larger request bodies on
non-Enterprise plans. Raise it freely when nothing between the client and PageBox imposes a
smaller cap.

## Credential throttling

| Variable                 | Default | Is                                                                                    |
| ------------------------ | ------- | ------------------------------------------------------------------------------------- |
| `LOGIN_MAX_ATTEMPTS`     | `10`    | requests per IP and authentication endpoint per window, including successful sign-ins |
| `LOGIN_WINDOW_SECONDS`   | `300`   | the window                                                                            |
| `API_KEY_MAX_REQUESTS`   | `120`   | per deploy token, on every call                                                       |
| `API_KEY_WINDOW_SECONDS` | `3600`  | the window                                                                            |

Raise the attempt count for a team that shares one public address. The token limit bounds
what a leaked key is worth — a CI job uploads a handful of times an hour.

## Startup tasks

| Variable                         | Default | Does                                              |
| -------------------------------- | ------- | ------------------------------------------------- |
| `PAGEBOX_MIGRATE_ON_START`       | `true`  | applies pending migrations under an advisory lock |
| `PAGEBOX_ENSURE_BUCKET_ON_START` | `true`  | creates the bucket if it is missing               |

Switch either off to run it yourself. Any failure exits the process rather than serving
half-configured traffic.

## Compose-only

`POSTGRES_PASSWORD`, `MINIO_ROOT_USER`, `MINIO_ROOT_PASSWORD`, `PAGEBOX_PORT`, `MINIO_PORT`,
`MINIO_CONSOLE_PORT`, `POSTGRES_PORT`, `TRAEFIK_PORT`. They configure the bundled services,
not the application.

## Not yet in use

`PAGEBOX_BASE_DOMAIN`, `PAGEBOX_SUBDOMAIN_MODE` and `PAGEBOX_SITE_SUBDOMAINS` have no effect.
A site gets its own origin by being given a domain in the panel, not through configuration.
