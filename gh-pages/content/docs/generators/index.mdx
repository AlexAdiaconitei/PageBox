1. what to set, and with which slashes;
2. what that option prefixes on its own;
3. what it does **not** prefix, and the helper that does;
4. what to grep in the build before uploading it.

## Not listed here?

The option is nearly always called `base`, `baseUrl` or `basePath`, and the question to ask
its documentation is *"what does this rewrite, and what does it leave alone"*. Then build,
and grep the output for references that start at `/` and do not carry <Prefix />.

If it is a tool other people use, it is worth adding to
[`src/lib/preflight.ts`](/docs/deploy/base-paths#adding-a-generator) so the panel can name
it too.
