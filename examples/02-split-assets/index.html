Ink on the shelf

Riso ink is soy-based and never fully dries. It rubs. That is not a fault and we will not quote you a price that pretends otherwise.

How a job runs

  1. Separate

    You send layered artwork, or we split it. One greyscale file per drum.

  2. Proof

    Five sheets, printed on the stock you chose. Posted, not emailed.

  3. Run

    Colour one, dry overnight, colour two. Registration drifts about 1 mm.

  4. Trim

    Guillotined to size, interleaved with newsprint so the ink has somewhere to go.
