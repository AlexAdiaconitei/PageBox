Commands

Six commands. Everything else is a flag on sync.

Command What it does
init <dir> Index a directory. Run once per machine.
sync <remote> Move the difference, both ways.
status What would move, without moving it.
resolve Settle conflicts. See the guide.
verify Re-hash and compare against the index.
version Version and index format.

Flags worth knowing

Flag Effect
--dry-run Print the plan and stop.
--proofs-first Send JPEGs before raws.
--limit 2M Cap the transfer rate, bytes per second.
--since 2024-01 Only files shot after a date.
--one-way Send only. Nothing arrives on this machine.
Exit codes: 0 agreed, 2 conflicts left, 3 transfer failed. Cron on 2 is normal; cron on 3 is worth an email.
