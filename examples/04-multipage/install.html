tern / install

Install

One binary, no runtime. Put it on both machines — tern talks to itself over SSH and refuses to run against a version it does not recognise.

Homebrew

brew install ternsync/tap/tern

Release binary

Pick the build for the machine and drop it on the path.

# linux, x86-64
curl -fsSL https://example.invalid/tern/latest/linux-amd64 -o tern
chmod +x tern && sudo mv tern /usr/local/bin/

From source

git clone https://example.invalid/tern
cd tern && make install
Both ends matter: the index format changed in 0.7. Upgrade the machine at home first — an old client against a new index is refused, a new client against an old index silently reindexes everything.

Check it

tern version
# tern 0.9.2 (index format 3)
